# SmartLine Guardian — Dashboard

React + TypeScript + Vite frontend for the SmartLine Guardian transmission line monitor.

See the [root README](../README.md) for full project documentation and setup instructions.

## Quick Start

```bash
npm install
npm run dev   # http://localhost:5173
```

Requires the serial bridge (`serial-bridge/`) to be running on port 3001.

## Build

```bash
npm run build    # production bundle → dist/
npm run preview  # serve the built bundle locally
```
